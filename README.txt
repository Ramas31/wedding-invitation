Rama & Shreyank Wedding Invitation — Standalone Flipbook

Contents:
- index.html: flipbook website
- pages/: five invitation images from your PDF

PUBLISH WITH GITHUB PAGES:
1. Sign in to github.com and create a PUBLIC repository named wedding-invitation.
2. Upload index.html and the entire pages folder to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, branch main, folder /(root), and Save.
5. The link will usually be https://YOUR-USERNAME.github.io/wedding-invitation/

Important:
- GitHub Pages sites are public: anyone with the URL can view the invitation.
- Page-turning uses a publicly hosted PageFlip.js library, requiring internet access.
- The invitation artwork is unchanged from the uploaded PDF.
- For edits, replace images in the pages folder with new versions using the same names.
- To preview locally, run: python3 -m http.server 8000 (in this folder), then visit http://localhost:8000
